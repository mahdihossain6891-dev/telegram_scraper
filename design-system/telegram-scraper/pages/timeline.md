# Timeline override — Criminal Timeline

Overrides Master for the **Timeline** page.

## Purpose

Per-suspect chronological narrative of flagged activity:
- Joined group / channel (first observed activity)
- Mentioned keyword
- Posted weapon media
- Shared phone / email / link

## Layout

1. Suspect list (left) — risk-sorted, search
2. Vertical day-grouped timeline (right) — event type filter

## Visual rules

- Soft white cards on `#F4F5F9`
- Purple spine + colored markers by event kind
- No emoji icons; pill kind labels only
- Match Growlytics Soft-UI density
